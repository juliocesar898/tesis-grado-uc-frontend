# DeepSignal - Interfaz de Usuario (Frontend)

Este repositorio contiene la interfaz de usuario (UI) para **DeepSignal**, un sistema de clasificación automática de señales de radiofrecuencia desarrollado como Proyecto de Grado para la **Universidad de Carabobo**. 

La aplicación está diseñada bajo un enfoque de **diseño minimalista** alineado con los estándares estéticos de *Material Design*, optimizada para ofrecer una visualización clara, moderna y en tiempo real del análisis espectral y las inferencias generadas por el motor de Inteligencia Artificial.

## 🚀 Características Principales

* **Visualización en Tiempo Real:** Renderizado fluido de espectrogramas y datos de señales IQ procesados por el backend.
* **Módulo de Inferencia:** Panel limpio que despliega el tipo de modulación detectada junto con el porcentaje de confianza del modelo predictivo (CNN).
* **Control de Captura:** Panel operativo para interactuar de forma abstracta con los scripts que gestionan el hardware SDR (HackRF One).
* **Diseño Minimalista:** Interfaz limpia y scannable que prioriza los datos de telecomunicaciones sin sobrecargar la pantalla.

## 🛠️ Stack Tecnológico

* **Framework:** React
* **Herramienta de Construcción:** Vite (configurado para un alto rendimiento con HMR rápido)
* **Estilos/UI:** Material Design / Google Design Aesthetics
